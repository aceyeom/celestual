# 나무증권 무한매수법 — 5년 백테스트

3배 레버리지 ETF에 적용하는 "무한매수법"(나무증권식 변형)을 **최근 5년
(2021-10-01 ~ 2026-10-02)** 구간에서 일 단위로 시뮬레이션한 코드와 결과입니다.

- 전략 상세 규칙, 가정, 결과 해석은 **[`results.md`](./results.md)** 참고.
- 실행: `python3 engine.py` (pandas/numpy만 필요)

## 데이터 출처 (중요)

이 샌드박스에서는 야후/스투크 등 **실시간 시세 API가 모두 차단**되어 있어,
도달 가능한 유일한 실측 일봉 데이터인 **QQQ·SPY 일봉 OHLCV(2026-10-02까지)**
를 공개 GitHub 데이터셋에서 받아 썼습니다.

- 원본: `UtkarshOver9000/Stock-price-predictor` → `data/QQQ.csv`, `data/SPY.csv`
  (Yahoo Finance via yfinance, 2026-10-04 수집). `data/source_meta.json` 참조.
- TQQQ·UPRO는 **직접 시세가 아니라** 기초지수 ETF로부터 재구성했습니다
  (3배 레버리지 ETF는 기초지수 **일간 수익률의 3배**를 추종하므로 종가 경로를
  높은 정확도로 복원 가능). `engine.py`의 `reconstruct()` 참고.
  - TQQQ ← QQQ (나스닥100 3배), UPRO ← SPY (S&P500 3배)
  - 비용: 운용보수 + 차입분(2배)에 대한 금융비용(근사 연준금리 스케줄).
  - **검증**: 복원된 TQQQ의 2022년 -79.2%, 2023년 +193.9%, 최대낙폭 -81.8%는
    실제 TQQQ와 거의 일치. UPRO도 동일하게 실측과 부합.

## 한계

- UDOW(다우 3배)는 이 환경에서 다우 일봉을 구할 수 없어 제외했습니다.
- 장중 고가/저가는 기초지수의 장중 움직임을 3배로 근사한 값이며 주문 체결
  판정에만 사용됩니다(종가 경로는 정확).
- 2026년 구간의 금융비용 금리는 마지막 관측치로 평탄 가정(모델 지식컷오프
  이후)이며 코드에 표시돼 있습니다.
- 환율(USD/KRW)은 모델링하지 않았습니다. 전략의 수익률(%)은 환율과 무관하며,
  사용자의 "1%=40만원"은 계좌를 100등분한다는 의미로만 사용했습니다.
