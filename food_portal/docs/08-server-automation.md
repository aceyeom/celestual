# 서버 자동화 방안 (PC 상시가동 불필요)

## 직접 답
**서버에서 24시간 자동화 가능하다. 내 PC를 켜둘 필요 없다.**
"PC" 권장은 '가장 안전한' 길이었을 뿐, 서버에 **차단회피 레이어**만 붙이면 된다.

## 핵심 구분 — 서버에서 그냥 되는 것 vs 레이어 필요한 것

| 작업 | 서버에서 | 비고 |
|---|---|---|
| TAAMs 조회 | ✅ 그냥 됨 | API/MCP |
| 본문·제목 자동 생성 | ✅ 그냥 됨 | LLM |
| 트렌드·뉴스 수집(구글/RSS) | ✅ 대체로 됨 | 읽기, 차단 약함 |
| **내 게시판(TAAMs) 업로드** | ✅ 그냥 됨 | 우리 서버니까 |
| 네이버 검색 스크래핑 | ⚠ 레이어 필요 | 데이터센터 IP 차단 가끔 |
| **네이버 블로그 포스팅** | ⚠ 레이어 필수 | 차단 핵심 지점 |

→ 즉 **네이버를 "건드리는 단계"만** 차단회피가 필요하고, 나머지는 서버에서 바로 된다.

## 차단회피 레이어 4가지 (네이버 접점에만)
1. **레지던셜/모바일 KR 프록시** — 데이터센터 IP 대신 가정용 IP로 나감 (가장 중요)
2. **로그인 세션 쿠키 재사용** — 사용자가 1회 로그인 → 쿠키 저장 후 재사용
3. **사람다운 속도** — 랜덤 지연, 하루 2~3건 소량 발행
4. **헤드풀(xvfb)** — 서버에서도 화면 있는 브라우저처럼 동작

## 추천 구성 3안

| 안 | 구성 | 네이버 IP | 비용 | 추천도 |
|---|---|---|---|---|
| **A. 집 미니PC/NAS 상시가동** | 라즈베리파이·중고PC·NAS 24시간 | **집=레지던셜(공짜)** | 1회 10~20만원 + 전기료 | ★ 차단·비용 최적 |
| **B. 클라우드 VPS + 레지던셜 프록시** | VPS가 전부 + 네이버만 프록시 경유 | 프록시 | VPS 월 5~2만원 + 프록시 월 수만원↑ | 확장성 좋음 |
| **C. 하이브리드** | VPS가 '두뇌'(조회·생성·스케줄) + 집 미니PC가 '손'(네이버 포스팅만) | 집=레지던셜 | VPS 소액 + 미니PC 1회 | ★ 안정+저렴 |

> **핵심 설계**: "두뇌(조회·생성·게시판·스케줄)"는 아무 서버에서나,
> "네이버에 올리는 손"만 레지던셜 IP에 두면 된다. C안이 이 분리의 정석.

## 리스크 (솔직히)
- 네이버 ToS상 자동 포스팅은 **회색지대**. 저속·소량·실계정·레지던셜로 리스크를
  관리하는 게임이지, "완전 안전"은 없다. 계정 분산·발행량 통제가 필수.

## 한 줄 결론
**서버 자동화 된다. 단 "네이버에 올리는 손"만 레지던셜 IP(집 미니PC 또는 레지던셜
프록시)에 두면, PC 상시가동 없이 24시간 돌릴 수 있다.** (추천: C안 하이브리드)
