# 2단계 산출물 — 이기는 공식 v1 (식품 상위노출 기준)

> 이 공식은 네이버 식품·정보성 블로그 상위노출 패턴에 대한 **도메인 지식 기반
> 기준선(v1)** 이다. 실시간 스크래핑이 불가한 환경 제약 때문에, 먼저 전문가
> 기준선을 확정하고 — 추후 사용자 PC에서 `src/tools`의 수집기를 돌려 나온
> 실제 상위글 지표로 **검증·보정(v2)** 한다. (보정 방법: `analyze.mjs`가
> 뽑은 중앙값과 아래 목표치를 비교해 차이가 크면 아래 수치를 교체)

방법론·추출 지표의 정의는 `04-reverse-engineering-method.md` 참고.

## 공통 공식 (세 주제 모두 적용)

| 항목 | 목표치 | 근거/의도 |
|---|---|---|
| **글자수(공백제외)** | **2,500~3,000자** | 식품 정보성 상위글 다수대 상회. 정보 밀도 우선, 억지 장문 금지 |
| **이미지** | **12장 이상** | 상위 정보성 글 평균 10~15장. **직접 제작/촬영 1장↑ 필수**(DIA+ 신호) |
| **소제목(목차)** | **4~6개** | 스캔 가능한 구조. 각 소제목에 **TAAMs 수치 1개↑** 배치 |
| **표** | **1개 이상** | 단가·건수 비교 표 → 체류·스크랩 유도 |
| **동영상** | 0~1개(선택) | 1개 삽입 시 체류시간 가점 |
| **어투** | **정중체(~습니다) 중심 + 친근체 가미** | 정보 신뢰 + 접근성 균형 |
| **첫 문단** | 핵심 키워드 2~3회 + **결론(핵심 수치) 선제시** | 이탈률↓, 체류↑ |
| **키워드 밀도** | 본문 전체 핵심키워드 **5~10회(약 1~2%)** | 제목 1회 + 소제목 분산 + 첫 문단 |
| **태그** | **10~20개** | 핵심 + 연관 키워드 |
| **문단** | 짧게(2~4문장), 8개↑ | 모바일 가독성 |

### 지수(C-Rank) 축적 — 글 밖의 조건
- 식품 **한 주제로 꾸준히** 발행(주 2~3회 규칙적).
- 체류시간·댓글·공감·스크랩을 유도(질문형 마무리, 저장 유도 표/체크리스트).
- **독창성 레버 = TAAMs 1차 데이터**(통관 건수·단가·수출사·산지 지도). 경쟁글이
  못 가진 자료라 DIA+ 통과의 핵심.

## 주제별 보정

### ① 통관현황 시사 리포트 (customs-report)
- 글자수 **2,800~3,500자**(데이터 많음) · **표 2개↑ + 차트 2개**
- 어투 **정중체 강하게**(리포트 톤)
- 필수 수치: 통관 건수, 수출국 비중 TOP, 단일 수출사 TOP, 반전 포인트(국가 1위 ≠ 수출사 1위)

### ② 올리브유 수입단가 (olive-oil)
- 글자수 **2,500~3,000자** · **브랜드/용량·단가 비교표 필수** · 이미지 **15장↑**(제품 중심)
- 어투 **정중체 + 친근체 혼합**(구매 고민 독자)
- 필수 수치: 브랜드별 통관 건수·단가, 원산지(스페인·이탈리아 등), 용량당 단가 비교

### ③ 노르웨이 연어 추적 (norway-salmon)
- 글자수 **2,500~3,000자** · **산지 지도 1 + 산지/수출사 이미지 다수**
- 어투 **친근체 비중↑**(스토리텔링) + 사실 구간은 정중체
- 필수 수치: 수출사별 통관 실적(MOWI·SALMAR·LEROY), 노르웨이 수입 비중, 산지 위치

## v1 → v2 보정 체크리스트 (사용자 PC 수집 후)
1. `src/tools`에서 `node collect.mjs && node analyze.mjs` 실행
2. `output/formula-<topic>.json`의 관측 중앙값 확인
3. 위 "목표치"와 비교 → 글자수·이미지·소제목 차이가 ±30% 넘으면 이 문서 수치 교체
4. 교체 시 이 파일을 v2로 갱신하고 커밋
