# food_portal — TAAMs 네이버 블로그 자동 포스팅 프로젝트

TAAMs(정식 수입식품 B2B 마켓)의 기능과, 수입식품·국내 농산물 경매 데이터를
근거로 한 **시사성 리포트**를 네이버 블로그에 자동 생성·포스팅하고, 동시에
TAAMs 게시판에도 업로드하기 위한 작업 공간이다.

> ⚠️ 이 디렉터리는 CELESTUAL 본체 코드와 **독립**이다. 네이버 블로그 자동
> 포스팅은 CELESTUAL 제품과 무관하므로 섞지 않는다. 최종 배포 위치는 4단계에서
> 확정한다.

---

## 목표

1. **블로그 주제** — 반드시 **TAAMs가 실제로 제공 가능한 데이터**에 근거하고,
   **사실에 기반**해야 한다.
   - TAAMs 기능 설명
   - 수입식품 및 국내 농산물 경매 품목 관련 시사성 리포트 (TAAMs 게시판에도 업로드)
2. **필요 기능**
   - 주제에 맞는 블로그 자동 생성 — 네이버 식품업종 블로그 **1위**가 목표.
     1위 글의 목차·내용·형태·어투를 분석해 역설계한다.
   - 네이버로부터 **차단되지 않는 방법**으로 자동 생성·포스팅 (computer-use 등).

---

## 단계 로드맵

| 단계 | 내용 | 상태 |
|---|---|---|
| **1단계** | TAAMs 제공 데이터 확인 → 사실 기반 주제·제목 확정 | ✅ 완료 (`docs/01-taams-data-capabilities.md`) |
| **2단계** | 네이버 검색 1위 글 역설계 (목차·글자수·어투·형태 분석) | ✅ 이기는 공식 v1 확정 (`docs/05-winning-formula.md`) — 추후 `src/tools` 실측으로 v2 보정 |
| **3단계** | TAAMs 실데이터로 본문 자동 생성 (이기는 공식 구조에 맞춰) | ⬜ 다음 단계 |
| **4단계** | 네이버 차단 회피 자동 포스팅(computer-use) + TAAMs 게시판 업로드 | ⬜ 예정 |

## 핵심 제약 (반드시 유지)

- 이 클라우드 세션은 네이버(및 임의 외부 호스트)에 **네트워크 접속이 차단**되어
  있다. 따라서 수집·포스팅의 **실행**은 이 환경에서 불가능하다.
- 네이버 차단 회피의 본질상(데이터센터 IP·헤드리스 지문·기계적 속도·무로그인
  세션이 차단 유발), **수집·포스팅 코드는 여기서 만들어 커밋하고, 실행은
  사용자 PC(실제 브라우저 프로필·로그인 세션·정상 IP)** 에서 한다.
- TAAMs 데이터를 답변·본문에 쓸 때 출처 표기는 원천 기관이 아니라 **TAAMs**:
  `출처: TAAMs (식품의약품안전처 수입식품 통관실적 기반)`
